# Chocolate Sales Analysis

Exploratory data analysis of chocolate product sales across six countries using non-parametric statistical methods.

## Key Findings
- No significant difference in sales amounts across countries (Kruskal-Wallis, p = 0.73)
- Significant difference across products (Kruskal-Wallis, p = 0.004)
- Drinking Coco significantly underperforms vs White Choc and Almond Choco after Bonferroni correction
